# I build AI systems that turn noisy data into reliable growth loops.

I design and ship FastAPI, LLM, and automation systems for outreach, experimentation, and decision support—especially where correctness, observability, and human review matter more than raw speed.

## Featured repositories

### [Self-Optimising](https://github.com/annoyinglyanonymous/Self-Optimising)
A self-optimising outreach engine that uses a multi-armed bandit to learn which channels and message angles perform best, then feeds real reply outcomes back into the model to improve future sends.

### [Outreach-Automation](https://github.com/annoyinglyanonymous/Outreach-Automation)
A queue-based outreach pipeline that enriches contacts, finds profile matches, scrapes profile data, verifies matches with AI, drafts personalized copy, and only sends after a human approval.

### [RAG-Implementation](https://github.com/annoyinglyanonymous/RAG-Implementation)
A retrieval-augmented generation implementation focused on grounding LLM responses in structured knowledge and document retrieval for more reliable, explainable AI workflows.

## Results

### Self-Optimising
- Volume: ~3,200 leads processed
- Cost: ~$85 per 1,000 leads in API + sending costs
- Time saved: ~20 hours/week in manual experimentation and copy iteration
- Outcome: ~58% higher reply rate than static templates

### Outreach-Automation
- Volume: ~800–900 contacts per campaign
- Cost: ~$180–$250 per campaign in vendor APIs
- Time saved: ~15 hours per campaign in manual research and enrichment
- Outcome: standardized a previously manual process into a predictable, reviewable pipeline

### RAG-Implementation
- Volume: multiple document and retrieval experiments across knowledge-grounded workflows
- Cost: low incremental cost relative to using ungrounded LLM responses
- Time saved: reduced repeated manual lookups and response verification
- Outcome: improved answer grounding, lower hallucination risk, and faster iteration on retrieval strategies
