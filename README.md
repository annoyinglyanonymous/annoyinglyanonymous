## Featured Projects

### [Self-Optimising](https://github.com/annoyinglyanonymous/Self-Optimising)

A self-optimising outreach experimentation system that uses a **multi-armed bandit** to evaluate channels and messaging strategies based on real-world outcomes.

**What it demonstrates:**

* FastAPI backend
* Experimentation and optimization logic
* Multi-armed bandit algorithms
* LLM-assisted decision making
* Outcome tracking and feedback loops
* Automated experimentation

**Results:**

* ~3,200 leads processed
* ~$85 per 1,000 leads in API and sending costs
* ~20 hours/week saved in manual experimentation and copy iteration
* ~58% higher reply rate compared with static templates

* Queue-based processing
* API integrations
* Data enrichment
* Web data extraction
* LLM-based verification
* AI-assisted personalization
* Human-in-the-loop automation

**Results:**

* ~$180–$250 in vendor/API costs per campaign
* ~15 hours saved per campaign
* Converted a manual research process into a standardized and reviewable workflow
