### [Self-Optimising](https://github.com/annoyinglyanonymous/Self-Optimising)

A self-optimising outreach experimentation system that uses a **multi-armed bandit** to evaluate channels and messaging strategies based on real-world outcomes.

**What it demonstrates:**

* FastAPI backend
* LLM integration
* Multi-armed bandit experimentation
* Automated decision-making
* Outcome tracking and feedback loops
* Experimentation and optimization

**Results:**

* ~3,200 leads processed
* ~$85 per 1,000 leads in API and sending costs
* ~20 hours/week saved in manual experimentation and copy iteration
* ~58% higher reply rate compared with static templates
